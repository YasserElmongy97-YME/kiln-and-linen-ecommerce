**Status: draft — publish after end-to-end checkout, sandbox payment, order confirmation, and admin verification.** The production storefront, populated catalog, product details, and catalog search have been checked; the authenticated and payment flows have not yet been completed on production.

I’m excited to share **Kiln & Linen**, my full-stack e-commerce project completed as part of the @UneeQ Interns program.

Built with Next.js 16, React 19, TypeScript, PostgreSQL and Drizzle ORM, Kiln & Linen brings together a searchable product catalog, database-backed customer carts, checkout and transactional order handling, role-protected admin tools, and an HMAC-signed Payment Sandbox. The sandbox uses test scenarios only and does not process real payments.

The repository includes 111 declared automated test cases across unit, PostgreSQL integration and HTTP end-to-end suites. I verified that all 26 unit tests pass in this environment; the database-dependent integration and end-to-end suites still need to be run against a reachable PostgreSQL database.
