# LinkedIn announcement

I’m excited to share **Kiln & Linen**, my full-stack e-commerce project completed as part of the @UneeQ Interns program.

Built with Next.js 16, React 19, TypeScript, PostgreSQL and Drizzle ORM, Kiln & Linen brings together a searchable homewares catalog, customer accounts and carts, checkout, order history, and a role-protected admin dashboard.

I verified the live customer checkout from cart through order confirmation using the Payment Sandbox. The test order appears as paid, and the existing admin account successfully opened the overview and order-detail pages. Sandbox payments are simulated; no real card is charged. The live walkthrough shows the storefront, catalog and privacy-redacted admin order screens; the checkout itself was verified separately in the browser.

**Live Demo:** https://kiln-and-linen-ecommerce.vercel.app
